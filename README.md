# Centum^100 🎓
**Empowering students to clarify every doubt, absolutely free.**

## 🌟 Overview
Centum^100 is a dedicated platform designed for **Class 8, 9, and 10** students to find instant, specific NCERT solutions. I created this to help students achieve perfect scores by making doubts easy to solve.

## ✨ Key Features
*   🔍 **Smart Doubt Solver:** Powered by Google to find exact NCERT answers.
*   ⚡ **Instant Access:** No more scrolling through long PDFs.
*   🆓 **100% Free:** High-quality education for everyone.

## 🚀 How to Use
1. Visit the live site: https://github.io
2. Type your question in the search bar.
3. Sign up to join our community of learners!
